# Security policy

## Supported versions

Security fixes are applied to the latest released version on the `main` branch. Older releases are not guaranteed to receive patches.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository if it is enabled. If private reporting is unavailable, contact the repository owner through the email address shown on their GitHub profile and include **FlixTranslate security report** in the subject.

Provide a clear description, affected version, reproduction steps or proof of concept, impact, and any suggested mitigation. Please avoid including Netflix credentials, personal data, or copyrighted subtitle content.

We will acknowledge a valid report, investigate it privately, and coordinate a fix and disclosure timeline with the reporter.
