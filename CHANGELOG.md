# Changelog

All notable changes to FlixTranslate are documented here. This project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-09

### Added

- Initial public release of the Manifest V3 Chrome extension.
- On-device subtitle translation, synchronized rendering, local caching, and import/export workflows.
- English, Japanese, Arabic, and French interface localizations.
- Reproducible Chrome packaging and tag-driven GitHub Release workflow.
