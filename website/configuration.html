First translation

  1. Open a supported title with text subtitles.
  2. Open the SubMate popup and choose a target language.
  3. Select Start translation. Chrome may download language data the first time an on-device language pair is used.

Options page

Open SubMate's options page from Chrome Extensions or the popup. You can select a source-language preference, choose how original and translated captions are displayed, adjust typography and overlay appearance, set a light/dark/system theme, clear cached translations, and import or export subtitle packages.

When a language pair is unavailable

Chrome determines whether its on-device Translator API supports a pair at runtime. If it does not, use an imported translation package or configure a cloud provider you trust. See AI translation for the data and key-handling details.

Permissions

SubMate requests only the streaming hosts it supports at install. Cloud provider hosts are optional: Chrome asks only when you choose that provider. Rejecting that request leaves cloud translation disabled for that provider.
